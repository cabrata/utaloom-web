BEFORE YOU PRESS PLAY

Hello, Windows.

  1. Download the MSI installer.
    Pick the Windows file from the latest release.
  2. Open it and follow the installer.
    The Java runtime and libVLC are bundled.
  3. Open Utaloom.
    Find a favorite and start listening.

SmartScreen note
The installer is not signed yet, so Windows may show a warning. Make sure the file comes from cabrata/utaloom before you continue.

Hello, Linux.

  1. Pick the package for your distro.
    DEB for Debian/Ubuntu, RPM for Fedora.
  2. Install with your package manager.
    Use the name of the file you downloaded.sudo apt install ./file-name.debsudo dnf install ./file-name.rpm
  3. Open Utaloom.
    Java is bundled. Your package manager handles libVLC.

Another distro?
If one is available, use the portable build and install VLC. Fedora may need RPM Fusion for some codecs. Full instructions are in the desktop repository ↗.

Hello, Android.

  1. Pick the APK you need.
    The standard build, or the Google Cast variant when available.
  2. Open the APK file.
    Allow installs from the browser or file manager you are using.
  3. Install, then press play.
    Requires Android 8.0 or newer.

Separate Android repository
APKs come from cabrata/utaloom-android, not the old APK in the desktop repository. Data from the old app is not migrated automatically.

A FEW GOOD QUESTIONS

Get to know us.

Is Utaloom free?

Yes. Utaloom is an open source project under GPL-3.0. The desktop and Android source code is public on GitHub.

Why are the desktop and Android versions different?

They share the Utaloom name and identity, but each has its own codebase and release cycle. This page pulls the latest stable release from each repository directly.

What if the download buttons do not show up?

The GitHub API has a request limit and needs an internet connection. Press Try again, or use the Desktop releases and Android releases links above. If no package for your platform has been published, the page says so instead of making up a download link.

Is there a macOS or iOS version?

Utaloom is available for Linux, Windows, and Android. There is no official macOS or iOS build yet.

Where do I report a problem?

For desktop, use desktop GitHub Issues. For Android, use Android GitHub Issues. Utaloom is an independent project, not an official Google or YouTube app.

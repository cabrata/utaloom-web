INSTALL STEPS

Windows

  1. Download the MSI.
    Grab the Windows file from the release list.
  2. Run the installer.
    The Java runtime and libVLC are bundled.
  3. Open Utaloom.
    Pick a song and press play.

SmartScreen
The installer is not code-signed yet, so Windows may warn you. Check that the file came from cabrata/utaloom before running it.

Linux

  1. Pick the package for your distro.
    DEB for Debian and Ubuntu, RPM for Fedora.
  2. Install it with your package manager.
    Use the name of the file you downloaded.sudo apt install ./file-name.debsudo dnf install ./file-name.rpm
  3. Open Utaloom.
    Java is bundled. libVLC comes from your package manager.

Other distros
Use the portable build with VLC installed. Fedora may need RPM Fusion for some codecs. Full instructions are in the desktop repository ↗.

Android

  1. Pick an APK.
    The standard build, or the Google Cast variant when it is published.
  2. Open the APK file.
    Allow installs from the browser or file manager you use.
  3. Install and open it.
    Requires Android 8.0 or newer.

Separate repository
APKs come from cabrata/utaloom-android, not the older APK in the desktop repository. Data from the old app is not migrated automatically.

QUESTIONS

Before you install.

Is Utaloom free?

Yes. It is licensed under GPL-3.0. The desktop and Android source code is public on GitHub.

Why are the desktop and Android versions different?

They share the Utaloom name, but each has its own codebase and release cycle, so version numbers do not match. This page fetches the latest stable release from both repositories.

What if the download buttons do not show up?

The GitHub API has a rate limit and needs a connection. Press Try again, or open the Desktop releases and Android releases links above. If a package for your platform has not been published, the page says so rather than showing a link that does not work.

Is there a macOS or iOS version?

No. Utaloom ships for Linux, Windows, and Android only.

Where do I report a problem?

Desktop bugs go to cabrata/utaloom issues. Android bugs go to cabrata/utaloom-android issues. Utaloom is an independent project, not an official Google or YouTube app.

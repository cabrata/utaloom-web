SEBELUM TEKAN PLAY

Halo, Windows.

  1. Download installer MSI.
    Pilih file Windows dari rilis terbaru.
  2. Buka dan ikuti instalasi.
    Java runtime dan libVLC sudah disertakan.
  3. Buka Utaloom.
    Temukan lagu favorit dan mulai mendengarkan.

Catatan SmartScreen
Installer saat ini belum ditandatangani. Windows mungkin menampilkan peringatan. Pastikan file berasal dari cabrata/utaloom sebelum melanjutkan.

Halo, Linux.

  1. Pilih paket distribusimu.
    DEB untuk Debian/Ubuntu, RPM untuk Fedora.
  2. Install dengan package manager.
    Gunakan nama file yang kamu download.sudo apt install ./nama-file.debsudo dnf install ./nama-file.rpm
  3. Buka Utaloom.
    Java sudah dibundel. libVLC ditangani package manager.

Distribusi lain?
Jika tersedia, gunakan build portable dan install VLC. Fedora mungkin memerlukan RPM Fusion untuk codec tertentu. Panduan lengkap ada di repository desktop ↗.

Halo, Android.

  1. Pilih APK yang kamu butuhkan.
    Versi standar, atau varian Google Cast bila tersedia.
  2. Buka file APK.
    Izinkan instalasi dari browser atau file manager yang kamu gunakan.
  3. Install, lalu tekan play.
    Memerlukan Android 8.0 atau lebih baru.

Repository khusus Android
APK diambil dari cabrata/utaloom-android, bukan APK lama di repository desktop. Data aplikasi lama tidak dimigrasikan otomatis.

A FEW GOOD QUESTIONS

Biar makin kenal.

Apakah Utaloom gratis?

Ya. Utaloom adalah proyek open source dengan lisensi GPL-3.0. Source code desktop dan Android terbuka di GitHub.

Kenapa versi desktop dan Android berbeda?

Keduanya berbagi nama dan identitas Utaloom, tetapi memiliki codebase serta siklus rilis terpisah. Halaman ini mengambil rilis stabil terbaru dari masing-masing repository secara langsung.

Bagaimana kalau tombol download belum muncul?

GitHub API punya batas permintaan dan memerlukan koneksi internet. Tekan Coba lagi, atau gunakan tautan Rilis Desktop dan Rilis Android di atas. Kalau paket untuk platformmu belum dipublikasikan, halaman ini akan memberi tahu tanpa membuat tautan download palsu.

Apakah tersedia untuk macOS atau iOS?

Saat ini Utaloom tersedia untuk Linux, Windows, dan Android. Belum ada build resmi untuk macOS atau iOS.

Di mana melaporkan masalah?

Untuk desktop, gunakan GitHub Issues desktop. Untuk Android, gunakan GitHub Issues Android. Utaloom adalah proyek independen, bukan aplikasi resmi Google atau YouTube.
